# Contributing to Yocare

Yocare is a proprietary digital product ecosystem. This repository is public for visibility and collaboration, but public access does not mean that Yocare-owned code, designs, documentation, or brand assets are open source.

## Before opening an issue or pull request

- Keep reports focused on reproducible bugs, accessibility, reliability, and documentation.
- Do not include credentials, private user data, private stream URLs, contracts, or other confidential information.
- Do not submit unlicensed code, artwork, logos, channel assets, media, or stream sources.
- Do not assume that opening a pull request grants Yocare ownership of your contribution or grants you rights to use Yocare materials.
- For substantial code or creative contributions, contact the maintainer first and agree on written contribution and intellectual-property terms before submitting the work.

## Security issues

Do not report vulnerabilities in public issues. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).

## Third-party material

Keep all third-party licence and attribution notices intact. Review [NOTICE.md](NOTICE.md) before changing imported source material, channel data, or external assets.

## Review and acceptance

Submitting a pull request does not guarantee that it will be accepted or merged. Maintainers may request changes or close contributions that do not meet project, security, rights, or product requirements.
